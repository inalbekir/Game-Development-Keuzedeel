# Omschrijving van mijn ontwikkelomgeving

Voor het bouwen van mijn game gebruik ik de volgende hardware en software:

---

## Hardware

- **Apparaat**: MacBook Pro  
- **Model**: MacBook Pro 14-inch, 2023  
- **Processor**: Apple M3 Pro-chip  
- **Geheugen**: 18 GB RAM

---

## Besturingssysteem

- **macOS Sonoma 14.6.1**

---

## Software

- **Python 3.12.6**  
  Voor het schrijven en uitvoeren van de code van mijn game.

- **raylib** (geïnstalleerd via Homebrew)  
  Een grafische programmeerbibliotheek waarmee ik zelf de rendering, besturing en game-logica programmeer.

- **raylib-py**  
  De officiële Python-binding van raylib, waarmee ik raylib kan gebruiken in mijn Python-project.

- **PyCharm**  
  Een professionele IDE die ik gebruik om mijn code overzichtelijk te schrijven en uit te voeren.

- **Git en GitHub**  
  Ik gebruik Git voor versiebeheer, met een online repository op GitHub waar ik regelmatig updates push met duidelijke commit messages.
